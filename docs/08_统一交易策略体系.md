## 🏗️ 第二章：多时间框架分析（从大到小）

### 2.1 周级判断（每周日/周一早上）

> 来源：日内交易系统规格书 V1.0

```
输入: 过去 7 天 ETH 数据
判断:
  ① EMA20/EMA50 位置关系 → 周趋势方向
  ② RSI 周级位置（<30 超卖 / 中性 / >70 超买）
  ③ ATR 波动等级（高/中/低）
  ④ 各窗口涨跌比
输出: 本周偏多 / 偏空 / 双向
```

### 2.2 日级判断（开盘前）

> 来源：日内交易系统 + 五重验证报告

```
输入: 当日 ETH 基础数据
判断:
  ① 日振幅已走百分比 → 剩余空间
  ② 连涨/连跌天数 → 趋势疲劳
  ③ Funding Rate → 多空情绪极端
输出: 今日适合做 / 不适合做 / 只做某方向
```

### 2.3 4H 级别过滤（入场前）

> 来源：4H K线延续策略（林火纸）

```
检查最近一根 4H K 线：
  ① 实体占比 > 70% → 方向坚决，顺势可做
  ② 实体占比 < 30% → 十字星，方向不明，跳过
  ③ Squeeze Momentum 方向 → 额外确认
```

## 🎯 第三章：入场系统（五重共振 + 回调入场）

### 3.1 五重共振门（全部绿灯才进场）

> 来源：日内交易系统规格书 + V92 参数

| # | 维度 | 做多绿灯 ✅ | 做空绿灯 ✅ | 红灯 ❌ |
|---|------|-----------|-----------|--------|
| 1 | **POC方向** | POC 上移 >5pt | POC 下移 >5pt | POC 变动 <5pt |
| 2 | **RSI 位置** | RSI < 60 | RSI > 40 | 做多时 RSI>60 / 做空时 RSI<40 |
| 3 | **日振幅已用%** | <70% 跟势 / >70% 反转 | <70% 跟势 / >70% 反转 | — |
| 4 | **K棒结构** | 近3根无长上影(>40%) | 近3根无长下影(>40%) | 有反向影线 |
| 5 | **ATR 波动** | ATR ≥ 8pt | ATR ≥ 8pt | ATR < 8 或 ATR > 55 |

### 3.2 入场方式：回调入场（非冲单）

> 来源：日内交易回测验证

```
回调进 = 60%胜率 + $3,792 净利
开盘冲 = 39%胜率 - $2,508 净利
```

**具体操作：**
- 做多：等窗口前 20 分钟内的**低点**进场
- 做空：等窗口前 20 分钟内的**高点**进场
- 回调到 POC ±5pt 范围 = 最佳入场点
- 超过 POC 15pt = 不追

### 3.3 Opening Candle Rejection（开盘影线反转入场）🆕

> 来源：Bilibili BV1zHBiBtEVf（TTrades / 不聪明钱交易）

**核心逻辑**：捕获特定开盘时刻的**诱导影线（Judas Swing）**

```
窗口开盘后第一根 1 分钟 K 线：
  做空信号: 影线在上，且 上影线 > 实体 → Rejection
  做多信号: 影线在下，且 下影线 > 实体 → Rejection

时间窗口（北京时间）:
  08:00 — 亚洲早盘/BTC 波动
  15:00 — 伦敦开盘
  22:00 — 纽约开盘冲刺

出场: 窗口开启 1 小时后收盘
```

**关键洞察**：V93 全天操作亏钱，V95 限制在 08/15/22 三个**高流动性注入点**后盈利 → 时间过滤是最重要的 edge。

### 3.4 操纵蜡烛识别 + 盒子理论 🆕

> 来源：Bilibili BV1zHBiBtEVf（视频深度提取 0:00-10:00）

```
核心框架: 15 分钟时间框架

① 定义 "开盘范围 (Opening Range)" — 前 15 分钟高低点
② 识别 "操纵蜡烛 (Manipulation Candles)":
   - 机构用影线诱导散户进场
   - 散户被诱导后，反向做头皮交易
③ ATR 确认波动 + Rumer's Box Theory（盒子理论）限定范围
④ 四种核心 K 线形态（影线长短是关键）

策略本质: 识别机构操纵 → 在散户被诱导进场后 → 反向交易
```

### 3.5 VWAP 三支柱辅助入场

> 来源：V52c VWAP+CVD 三支柱策略

| 支柱 | 作用 | 信号 |
|------|------|------|
| ① VWAP Bounce/Rejection | 开点位 | 价格碰 VWAP 后反弹/下杀 + 拒绝K棒 |
| ② CVD Divergence | 判方向 | 价格新低 + CVD 没新低 = 做多背离 |
| ③ VP 结构 | 背景环境 | SL 设在 LVN 后，TP 设在下一个 HVN 前 |

### 3.6 大单订单流入场过滤 🆕

> 来源：Learning Trading Strategies — 大单监控引擎方案


### 5.2 追踪止盈法则

> 来源：K线基础入门教程（B站经济学院）

```
弃用固定止盈位，采用"移动止损"模式：
  1. 浮盈 12pt → SL 移至入场+3pt（锁定保本）
  2. 每浮盈 10pt → SL 跟涨 10pt
  3. 让盈利持续奔跑，以有限止损博取趋势利润
```

## 🕯️ 第六章：K 线形态库

### 6.1 入场确认形态（裸K信号）

> 来源：18种K线形态教学（徐九年） + K线基础入门教程

#### 做多信号

| 形态 | K线特征 | 确认条件 |
|------|---------|---------|
| **锤子线** | 长下影 + 小实体在上 | 出现在支撑位/VWAP |
| **看涨吞没** | 第二根阳线完全包住第一根阴线 | 量>前一根 |
| **晨星** | 阴线→十字星→阳线 | 第三根突破第一根50% |
| **W底/双底** | 两次探底不破 | 颈线突破确认 |
| **接针** | 急跌后秒拉 | 下影 > 实体 2 倍 |

#### 做空信号

| 形态 | K线特征 | 确认条件 |
|------|---------|---------|
| **射击之星** | 长上影 + 小实体在下 | 出现在阻力位 |
| **看跌吞没** | 第二根阴线完全包住第一根阳线 | 放量 |
| **黄昏星** | 阳线→十字星→阴线 | 第三根跌破第一根50% |
| **M头/双顶** | 两次冲高不破 | 颈线跌破确认 |

### 6.2 K 线过滤规则

> 来源：V52 六步入场流程

```
实体占比 > 70% → 方向坚决（延续性高）
上影/下影 > 40% → 方向犹豫（出场或不入场）
连续 3 根同方向实体 → 趋势确认
十字星 / Doji → 观望不做
```
